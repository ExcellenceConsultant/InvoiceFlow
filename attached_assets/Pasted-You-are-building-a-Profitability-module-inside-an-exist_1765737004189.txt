You are building a Profitability module inside an existing Invoice Flow web application.

🔐 Access Control
This module must be accessible only to Super Admin role

Other roles must not see this module in UI or API responses


📌 Module Purpose
The Profitability module calculates profit margin based on Margin per Carton and shows:

Item-level margin

Invoice-level total margin

Customer-wise and Product-wise margin reports


📐 Core Margin Logic
Margin is calculated per carton

Margin per carton is entered manually by Super Admin

Formulas:
Total Amount = Qty (cartons) × Rate per carton

Total Margin = Qty (cartons) × Margin per carton

Margin % = (Total Margin / Total Amount) × 100


📋 Invoice-Wise Profitability Table
Create a table with the following columns:

| SR No | Item Code | Product Name | Qty (Cartons) | Rate per Carton | Margin per Carton (Input) | Total Amount | Total Margin |

Rules:
Margin per carton must be editable only by Super Admin

Total Margin should auto-recalculate on margin change

Store margin at invoice-item level
